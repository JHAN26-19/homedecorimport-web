# WALL PANEL — Sitio comercial

Sitio web estático, responsive y editable para presentar soluciones de acabados arquitectónicos.

## Abrir en el navegador
1. Descomprime `wallpanel-web.zip`.
2. Abre la carpeta.
3. Haz doble clic en `index.html`.

No necesita instalar Node ni dependencias para visualizarse.

## Editar en Visual Studio Code
Abre la carpeta descomprimida en Visual Studio Code. Los archivos principales son:

- `index.html`: textos, secciones, teléfonos, enlaces y estructura.
- `styles.css`: colores, tipografías, composición responsive y tarjetas visuales.
- `script.js`: navegación suave y animaciones ligeras.
- `assets/logo.jpeg`: logo/referencia visual entregado.

## Personalización rápida
- Cambia el color principal editando `--orange` en `styles.css`.
- Cambia teléfonos y enlaces de WhatsApp en `index.html`.
- Reemplaza `assets/logo.jpeg` si deseas utilizar un logo nuevo, conservando ese nombre.

La web incluye enlaces directos a WhatsApp, llamadas telefónicas y ubicación en Google Maps.

## Despliegue en GitHub, Ubuntu y Cloudflare

Consulta `GUIA_GITHUB_CLOUDFLARE_WALLPANEL.md` para subir el proyecto a GitHub, clonarlo en Ubuntu, levantar Docker y configurar Cloudflare Tunnel sin exponer el token.
